# Corpus provenance

Generated by ``hivemind corpus pull``. Each source pins a specific commit so
rebuilds are reproducible. See ``src/hivemind/corpus/sources/`` for the
adapter code.

## Refreshing the corpus

```bash
hivemind corpus pull --sources anthropic_skills --sources openhands_microagents
hivemind corpus build
```

To bump a pinned commit, edit ``COMMIT_SHA`` in the adapter module and re-run
``hivemind corpus pull``. Old skill files for that source are overwritten
in-place (filename = ``<source>__<id>.md``).

## Audit results

Ingestion runs every skill body through ``src/hivemind/corpus/security_audit.py``.
Skills with status ``failed`` are dropped from ``skills.jsonl``;
``manual_review_required`` skills are kept but flagged. Both classes are
appended to ``corpus/audit_log.jsonl`` (gitignored — per-environment).

## Known false-positives

- `anthropic_skills__claude-api` currently trips the ``exfiltrate_secrets``
  regex because the body contains the string "post the api key" inside a
  code example. The skill is benign instructional content; a manual whitelist
  pass would re-include it. Tracked under Phase 3 audit work.
